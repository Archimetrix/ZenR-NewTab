🔒 GitHub Gist Backup — Setup Guide

①

Create a Token: GitHub → Profile → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic). Tick only the gist scope. ⚠️ Set expiration to No expiration.

②

Copy & save your token somewhere safe — GitHub shows it only once. You will need it to restore your ZenR data in the future.

③

Paste the token into ZenR and hit Send Backup. A private Gist is created automatically. To restore on a new device, just paste your token and hit Get & Restore — the extension finds your backup on its own.

Privacy & Data Handling

ZenR-NewTab is a 100% local-first extension. No accounts. No tracking. No servers. Everything stays on your device unless you explicitly opt in to an optional feature.

Your Data & Local Storage

All your bookmarks, board layouts, notes, widget positions, and appearance settings are saved exclusively using the browser's local storage API — stored only on your own device and never transmitted anywhere.

Background images and videos you upload are stored in your browser's local database (IndexedDB). They are entirely local and never leave your machine under any circumstance.

No data is ever sent to any ZenR server. There is no backend, no database, and no analytics pipeline tied to your usage.

Uninstalling the extension permanently deletes all locally stored data from your browser.

Search Suggestions Always On When Enabled

When you type in the search bar, your query is sent to the selected search engine's public autocomplete API to fetch suggestions. This is the same request your browser makes natively when you type in the address bar.

Google, DuckDuckGo, Brave, Ecosia, and Startpage all fetch suggestions via Google's public suggest endpoint. DuckDuckGo's own autocomplete blocks browser extensions, so Google's endpoint is used for the suggestion dropdown — your actual search still goes to whichever engine you've selected.

Bing fetches suggestions from its own public suggestion API directly.

Suggestions are cached in memory only for the duration of the current tab session and are discarded the moment you close or reload the tab.

You can disable suggestions entirely at any time via Settings → Search → Show Suggestions.

Pixabay Backgrounds Optional

Pixabay integration is entirely optional. It only activates if you manually enter your own personal Pixabay API key in Settings → Wallpaper. Nothing is fetched otherwise.

When active, your search query and API key are sent directly from your browser to Pixabay's API. ZenR is not involved in this request in any way — it is a direct connection between your browser and Pixabay.

Your Pixabay API key is stored locally on your device and is never transmitted to anyone other than Pixabay itself.

Fetched media links are saved locally. The actual images and videos stream directly from Pixabay's CDN to your browser — ZenR never proxies or stores that media.

You can remove your Pixabay key and all fetched media at any time using the Remove Key button in Wallpaper settings.

Moody Effects — Ambient Sounds Optional

Moody Effects is entirely optional. It only activates if you manually enter your own personal Freesound API key in Settings → Moody Effects. No network requests are made otherwise.

When you open a sound category, your search query and API key are sent directly from your browser to the Freesound API (freesound.org/apiv2). ZenR is not involved in that request — it is a direct connection between your browser and Freesound.

Audio streams directly from Freesound's CDN to your browser. ZenR never proxies, caches to disk, or stores audio data of any kind.

Your Freesound API key is stored locally in the browser using the same storage API as all other ZenR settings. It is never transmitted to anyone other than Freesound itself when a search is performed.

Backups & Exports: Your Freesound API key is included in JSON exports so your settings are preserved when you import them manually. It is not included in GitHub Gist backups. Treat export files like credential files and do not share them with others.

You can remove your key at any time using the Remove button in Settings → Moody Effects. This immediately stops all playback and clears the key from local storage.

GitHub Gist Backup Optional

GitHub Gist backup is completely optional. It only activates if you choose to enter a GitHub Personal Access Token (PAT) in Settings → Backup.

Your PAT is stored locally on your device and is only ever sent directly to GitHub's API as an authentication token — never to ZenR or any third party.

Backups & Exports: Your GitHub token is never included in Gist backups or JSON exports — it stays on your device only. When setting up ZenR on a new device, you will need to re-enter your token once in Settings → Backup.

Backups are triggered manually via the "Backup Now" button, or on a 24-hour auto-sync interval. A backup is never fired automatically on every single change you make.

To minimise risk, your GitHub token should be created with only the gist scope enabled — no repository access, no user data, no admin permissions of any kind.

Your backup file is stored as a private GitHub Gist under your own GitHub account. ZenR has absolutely no access to it.

You can revoke the token directly from your GitHub account settings at any time to permanently cut off access.

Issue Reports Optional

The "Report an Issue" form is entirely optional. Nothing is sent to anyone unless you explicitly click the Send Report button.

When you submit a report, your message and optional name are processed by Formbold, a third-party form service. Any screenshots you attach are optionally uploaded via Catbox.moe. Both are independent services with their own privacy policies.

No metadata about your bookmarks, notes, settings, or browsing activity is ever attached to a report. Only the text you write and the images you choose to upload are included.

What ZenR Never Does

Never tracks your browsing history or which links you click.

Never sends your bookmarks, notes, or settings to any remote server.

Never uses cookies, fingerprinting, or any form of user identification.

Never displays ads or uses advertiser-injected scripts.

Never requests permissions beyond what is declared in the extension manifest.

Never auto-syncs or phones home without your explicit action.

Never stores, caches, or transmits audio data — Moody Effects streams sound directly from Freesound's CDN to your browser with no ZenR intermediary.
